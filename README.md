# INSTINCT NEXUS · 인터랙티브 3D 파티클 웹사이트

> **이 사이트는 Instinct가 만들었습니다.**
> 모델(제작자) 비교 테스트용 프롬프트("사용자 인터랙션과 파티클 효과가 굉장한 3D 웹사이트")를 받아 처음부터 끝까지 제작한 정적 웹사이트입니다.

🔗 **라이브 데모**: https://sigco3111.github.io/instinct-nexus/

## 인터랙션

- **커서 반발·소용돌이**: 마우스 주변 입자가 밀려나며 회전합니다.
- **클릭/탭 충격파**: 클릭한 지점에서 링 모양 파동이 퍼지고 불꽃이 터지며 코어가 맥동합니다.
- **드래그 회전 + 관성**: 우주를 끌어서 돌리면 놓은 뒤에도 관성이 남습니다.
- **길게 누르기 중력**: 0.4초 이상 누르면 입자가 빨려 들어옵니다.
- **스크롤 모핑 + 속도 반응**: 스크롤에 따라 입자 형태가 바뀌고, 빠르게 스크롤하면 입자가 번쩍입니다.
- **키보드**: `1`~`5` 섹션 이동, `Space` 색상 팔레트 전환.
- **HUD**: 색상 팔레트 3종, 입자 밀도 슬라이더, 자동 회전 토글, FPS 표시.
- **적응형 성능**: FPS가 낮으면 입자 밀도를 자동으로 낮춥니다.

## 실행 환경에 대한 메모

- 원본 프롬프트의 "포트 20000에서 실행"은 로컬 CLI 전용 조건이라, 이 프로젝트는 **GitHub Pages**로 배포했습니다.
- 토큰 사용량과 API 비용은 이 환경에서 집계할 수 없어 기록하지 않았습니다.
- 로컬 실행: 폴더에서 `python3 -m http.server 20000` 후 http://localhost:20000 접속.
